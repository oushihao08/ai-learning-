# 武器卡 02：外聘律师四大收费猫腻与五句镇场鉴谎刀

**核心认知**：法律服务存在极强的**委托-代理利益错位**——律师赚的是代理费和免责安全，你要的是商业净回款与成交效率。用这套工具平视控场，没人敢拿行话忽悠你。

## 一、看穿四种收费模式背后的“隐藏动机”

1. **固定包干收费** → **防“收钱后劝降敷衍”**：签单前拍胸脯包赢，钱一到账就想花最少时间结案（派实习生套模板、庭上拼命劝你吃亏调解）。**锁死法**：按「立案及财保完成 / 一审判决 / 二审或回款」分阶段付款，锁死主办出庭律师姓名。
2. **风险代理（后端抽成）** → **防“按纸面判决书抽成”超级大坑**！无良条款写“按胜诉判决书或调解书确认金额抽 15%”——结果赢了 1000 万空壳白条（[[mm-05-waterfall-and-net-payoff]]），你一分钱没收到还得倒掏 150 万给律师！**锁死法**：合同白纸黑字写死**「仅以委托人银行账户实际收到/抵偿变现的净回款为唯一计费基数；撤诉、调解、对方主动履行减半封顶」**！（注：刑事、行政、群体劳动案法定禁止风险代理，谁收谁违规）。
3. **按小时计费** → **防“万字法理注水刷工时”**：1 页能说清的事写 20 页法条综述。**锁死法**：设定单事项工时封顶 Cap，禁贴法条原文。
4. **常年法顾包年** → **防“只堵不疏甩锅侠”**：为免责把一切新业务批成“存在风险建议审慎”。**锁死法**：强制要求所有意见按 **红灯（踩刑/必死）· 黄灯（算赔率给替代改法）· 绿灯（放行）** 交付，不给替代方案不算交差。

## 二、五句一开口就镇住全场的“鉴谎反问刀”

| 当律师忽悠你说…… | 你当场甩出去的内行追魂问 |
| --- | --- |
| **“这官司咱们占理，稳赢！”** | 「别只谈法理胜诉——**诉前财保能不能冻住他活水账户？一二审加执行总共耗时几个月？扣掉他在先抵押顺位，真能落袋几成现金？**」 |
| **“不按我说的全套整改马上出大事！”** | 「请把**法定强制红线**和**完美合规标准**拆开：同体量同行近两年因这条被实罚的概率和中位数是多少？给我一个花 10% 成本挡住 80% 风险的最小补丁。」 |
| **甩来几页“建议补充证据、友好协商”** | 「不要正确废话——直接告诉我**现在缺哪一张原始底账会在质证翻车**、**最晚哪天过除斥期**，并给我能直接发给对方的替换条款原文。」 |
| **“我在法院有硬关系，包搞定”** | **当场拉黑换人**（终身追责留痕制下 99% 是两头吃的信息差骗子：赢了归功他关系，输了怪上面盯得紧，还直接把你拖进刑事行贿深渊）。 |
| **“这商业模式有法律风险，不能干”** | 「我是请你帮我找**怎么改交易主体、分账或免责开关能合法干成**的路径，不是请你念禁止条文的——同行头部是怎么做结构隔离的？」 |
